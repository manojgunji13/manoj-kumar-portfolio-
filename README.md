# Manoj Kumar Gunji — Portfolio Website

A responsive single-page professional portfolio built from the supplied resume and profile photo.

## Files
- `index.html` — page structure and portfolio content
- `styles.css` — responsive styling
- `script.js` — mobile navigation and footer year
- `assets/profile.jpg` — supplied profile photograph
- `assets/Manoj_Kumar_Gunji_Resume.pdf` — supplied resume

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public GitHub repository (for example, `manoj-kumar-portfolio`).
2. Upload all files and folders from this project. Keep the `assets` folder in the same location.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

All content is based on the supplied resume. Review the dates and role title before publishing if you want any changes.
